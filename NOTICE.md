# Attribution

This project packages three third-party MIT-licensed skills. Each skill keeps its original `LICENSE`. Copyright notices in those LICENSE files must be preserved.

| Skill | What it does |
| --- | --- |
| cut-video | Tighten long recordings: remove silences, fillers, retakes |
| clipify | Long video → social-ready shorts (9:16, captions, face-pan) |
| slack-assets-bot | File dropped assets (files, YouTube links) into a local library |

Do not push this combined project to the `upstream-*` remotes (`upstream-cut-video`, `upstream-clipify`, `upstream-slack-assets-bot`).
